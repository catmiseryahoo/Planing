# Безопасность репозитория

- GitHub Actions в этом репозитории не используются. Каталог `.github/workflows/` не должен добавляться без отдельной проверки.
- Пароли, токены, приватные SSH-ключи и файлы `.env` нельзя сохранять в Git.
- Развёртывание выполняется вручную только с локального доверенного компьютера.
- Файлы, маскирующие исполняемый код под шрифты, изображения или архивы, запрещены.
- Служебные папки агентов, локальные сборки и автоматически созданные отчёты не публикуются в GitHub.
